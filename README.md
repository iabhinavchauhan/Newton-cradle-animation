# Newton Cradle Animation

A simple and interactive Newton Cradle animation built using HTML, CSS, and JavaScript. The project demonstrates the basic concept of motion and collision through a web-based animation.

## Live Demo

[View Live Demo](https://iabhinavchauhan.github.io/Newton-cradle-animation/)

## Features

* Interactive Newton Cradle animation
* Smooth ball movement
* Realistic swinging effect
* Simple and clean user interface
* Responsive design
* Built using basic web technologies

## Technologies Used

* HTML5
* CSS3
* JavaScript
* CSS Animations

## How It Works

The project uses HTML to create the structure of the Newton Cradle, CSS to style the balls and create the animation, and JavaScript to control the interaction and movement.

When the animation starts, the balls move in a sequence to simulate the basic working principle of a Newton Cradle.

```bash

```

Open `index.html` in your browser.
