# Newton Cradle Animation

A simple and interactive Newton Cradle animation built using HTML and CSS. 

## Live Demo

[View Live Demo](https://iabhinavchauhan.github.io/Newton-cradle-animation/)

## Technologies Used

* HTML5
* CSS3
* CSS Animations

## How It Works

The project uses HTML to create the structure of the Newton Cradle, CSS to style the balls and create the animation, and JavaScript to control the interaction and movement.

When the animation starts, the balls move in a sequence to simulate the basic working principle of a Newton Cradle.

## Getting Started

### Clone the Repository

```bash
git clone https://github.com/iabhinavchauhan/Newton-cradle-animation.git
```

### Open the Project

Navigate to the project directory:

```bash
cd Newton-cradle-animation
```

Open `index.html` in your browser.
